# Цены выбранных препаратов

В процедуре и продаже рядом с каждым выбранным препаратом снова отображаются цена за единицу и сумма строки. Сумма обновляется при изменении количества. Строка цены не заменяется подсказкой поэтапного складского учёта.

Для редактирования используется цена, сохранённая в записи; для нового препарата — текущая цена прайса. Подпись берёт цену из того же расчёта, что и общий итог. Изменение назначенной дозы само по себе не меняет количество оплачиваемых единиц.

Проверены отображение при трёх режимах учёта, пересчёт количества, цены ранее сохранённой процедуры и расположение на телефоне и компьютере. Модульные проверки также пройдены. Изменений базы данных нет.
