# Ручной ввод индивидуальной стоимости

Очищение стоимости больше не восстанавливает автоматически сумму прайса. Оба поля стоимости в процедуре и продаже сохраняют пустое состояние, пока пользователь вводит новую сумму, в том числе при изменении количества препаратов. Новая форма по-прежнему рассчитывает первоначальную стоимость автоматически.

Пустая стоимость не может быть сохранена как нулевая оплата. Проверки причин скидки, ранее полученной оплаты и подтверждения платежа сохранены.

Проверены удаление Delete/Backspace, потеря фокуса, ввод по цифрам, оба поля стоимости, продажа и процедура, изменение неоплаченной записи и сохранение суммы. Пройдены 194 модульные проверки и 40 браузерных сценариев, включая исправление оплаты и шаблоны. Изменений базы нет.
