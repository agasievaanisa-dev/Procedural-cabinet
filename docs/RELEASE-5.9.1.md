# Время оплаты без повторной даты посещения

В отчёте смены дата и время посещения и имя сотрудника остаются в заголовке пациента. В строке фактической оплаты показываются способ, сумма, скидка с комментарием и только время оплаты по Москве, например: «Оплачено: Терминал: 500 ₽ · со скидкой 300 ₽ (комментарий) · Время оплаты: 19:12».

Для привязанной к посещению оплаты убраны повторная дата, имя сотрудника и подпись «Оплата после процедуры» / «Оплата продажи». При нескольких платежах время указывается для каждого известного платежа. Если время неизвестно, программа не подставляет время посещения вместо времени оплаты. Для отдельной оплаты по записи вне списка смены дата и сотрудник остаются, потому что заголовка посещения рядом нет.

Оформление одинаково в приложении, предпросмотре, печатном HTML и PDF. Способы оплаты, скидки, комментарии и финансовые итоги сохранены. Изменений базы данных и финансовых записей нет.
